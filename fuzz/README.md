# AFL++ fuzzing (lab 6.4)

## One-time macOS setup (needs password)

```bash
sudo $(brew --prefix afl++)/bin/afl-system-config
```

Increases shared-memory limits and optionally unloads ReportCrash for faster fuzzing.
Reboot or re-load ReportCrash after you finish fuzzing sessions.

## Check environment

```bash
./fuzz/check_afl.sh
```

## Build harness

```bash
./fuzz/build_fuzz.sh fuzz    # instrumented binary for afl-fuzz
./fuzz/build_fuzz.sh cov     # coverage build (llvm profdata)
```

## Run fuzzing

```bash
./fuzz/run_fuzz.sh          # auto-resumes if fuzz/findings/default exists
FRESH=1 ./fuzz/run_fuzz.sh  # or: rm -rf fuzz/findings
```

Or manually:

```bash
source fuzz/afl_env.sh
afl-fuzz -i fuzz/corpus -o fuzz/findings -m none -t 1000 -- fuzz/mystring_fuzz @@
```

## Notes

- `AFL_NO_FORKSRV=1` is set by default on macOS (see `afl_env.sh`).
- Do **not** `export AFL_CXX` — it breaks `afl-clang-fast++` with long compile lines.
- Corpus seeds are generated by `fuzz/gen_corpus.py` during build.
